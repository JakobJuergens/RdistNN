# Back-compat alias for [`list_scores()`](https://JakobJuergens.github.io/RdistNN/reference/list_scores.md)

Back-compat alias for
[`list_scores()`](https://JakobJuergens.github.io/RdistNN/reference/list_scores.md)

## Usage

``` r
score_names()
```

## Value

character vector of names

## Examples

``` r
identical(score_names(), list_scores())
#> [1] TRUE
```
