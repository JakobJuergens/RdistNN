# Back-compat alias for [`distance_names()`](https://JakobJuergens.github.io/RdistNN/reference/distance_names.md)

Back-compat alias for
[`distance_names()`](https://JakobJuergens.github.io/RdistNN/reference/distance_names.md)

## Usage

``` r
list_distances()
```

## Value

Character vector of names.

## Examples

``` r
identical(distance_names(), list_distances())
#> [1] TRUE
```
