# Summarize a `gmm_result`

Summarize a `gmm_result`

## Usage

``` r
# S3 method for class 'gmm_result'
summary(object, level = 0.95, ...)
```

## Arguments

- object:

  A `gmm_result` object from
  [`gmm_dnn()`](https://JakobJuergens.github.io/RdistNN/reference/gmm_dnn.md).

- level:

  Confidence level.

- ...:

  Not used.

## Value

An object of class `summary.gmm_result`.
