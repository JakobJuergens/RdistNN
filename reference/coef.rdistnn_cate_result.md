# Extract coefficients from a `rdistnn_cate_result`

Extract coefficients from a `rdistnn_cate_result`

## Usage

``` r
# S3 method for class 'rdistnn_cate_result'
coef(object, ...)
```

## Arguments

- object:

  A `rdistnn_cate_result` object.

- ...:

  Not used.

## Value

Named numeric vector of point estimates (`object$tau`), one entry per
target point.
