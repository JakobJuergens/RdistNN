# Local IV-GMM Estimation

## Overview

> **Experimental companion functionality.** The local IV-GMM layer
> exists for ongoing companion-paper development; its API and theorem
> alignment may change before the GMM paper is released. It is not at
> the maturity level of
> [`np_dnn()`](https://JakobJuergens.github.io/RdistNN/reference/np_dnn.md),
> [`cate_dnn()`](https://JakobJuergens.github.io/RdistNN/reference/cate_dnn.md),
> or
> [`plqr_dnn()`](https://JakobJuergens.github.io/RdistNN/reference/plqr_dnn.md).

This vignette shows the local IV-GMM workflow built on
[`gmm_dnn()`](https://JakobJuergens.github.io/RdistNN/reference/gmm_dnn.md).
The example uses the doubly robust IV moment model created by
[`gmm_model_dr_iv()`](https://JakobJuergens.github.io/RdistNN/reference/gmm_model_dr_iv.md)
and the IV simulation DGPs exposed through
[`sim_iv_data()`](https://JakobJuergens.github.io/RdistNN/reference/sim_iv_data.md).

The full paper replication grid is intentionally kept out of the
vignette. It is installed with the package under
`inst/paper-replication/iv/` and can be located after installation with:

``` r

system.file("paper-replication/iv/run.R", package = "RdistNN")
system.file("paper-replication/iv/hpc", package = "RdistNN")
```

## One Local IV Dataset

[`sim_iv_data()`](https://JakobJuergens.github.io/RdistNN/reference/sim_iv_data.md)
returns a data frame with observed variables, oracle nuisance columns,
the target point `x0`, and the true local IV target `theta_x0`.

``` r

iv <- sim_iv_data(
  design = "dgp2_iv_homog_overid",
  n = 160L,
  kx = 2L,
  q = 2L,
  seed = 1L
)

head(iv$data[, c("X1", "X2", "Z1", "Z2", "D", "Y")])
```

## Fitting the DR-IV GMM Model

The DR-IV model factory records which columns contain the outcome,
treatment, instruments, and nuisance estimates. In this example the
nuisance columns are oracle values generated by the DGP.

``` r

model_iv <- gmm_model_dr_iv(
  y_col = "Y",
  d_col = "D",
  z_cols = c("Z1", "Z2"),
  pi_cols = c("piZ1_oracle", "piZ2_oracle"),
  muY_col = "muY_oracle",
  muD_col = "muD_oracle"
)

fit_iv <- gmm_dnn(
  data = iv$data,
  x_cols = c("X1", "X2"),
  x0 = iv$x0,
  model = model_iv,
  k = 1L,
  s = 12L,
  se = TRUE,
  return = "ess"
)

fit_iv$theta
#>       target_1
#> theta  0.51562
fit_iv$se
#>        target_1
#> theta 0.7900163
fit_iv$J
#>   target_1 
#> 0.09635039
fit_iv$pval_J
#>  target_1 
#> 0.7562541
fit_iv$neff
#> target_1 
#> 24.67559
```

[`summary()`](https://rdrr.io/r/base/summary.html) and
[`confint()`](https://rdrr.io/r/stats/confint.html) expose the same
fitted object in reporting form:

``` r
summary(fit_iv)
```

## Small IV Simulation

[`sim_iv_run()`](https://JakobJuergens.github.io/RdistNN/reference/sim_iv_run.md)
expands a grid over designs, sample sizes, covariate dimensions,
instrument counts, and Monte Carlo replications. The just-identified
design `dgp1_iv_justid_linear` is always run only once with realized
`q = 1`.

``` r

raw_iv <- sim_iv_run(
  designs = c("dgp1_iv_justid_linear", "dgp2_iv_homog_overid"),
  n_vals = 120L,
  kx_vals = 2L,
  q_vals = 2L,
  n_reps = 2L,
  master_seed = 42L,
  k = 1L,
  s_fn = function(n, kx) 10L,
  methods = "iv_oracle",
  verbose = FALSE
)

head(raw_iv)
```

[`summarise_iv_results()`](https://JakobJuergens.github.io/RdistNN/reference/summarise_iv_results.md)
aggregates to one row per `(method, design, n, kx, q)` cell and includes
local overidentification diagnostics when `q > 1`.

``` r

tab_iv <- summarise_iv_results(raw_iv)
```

## Paper Replication Scripts

The installed replication layer provides single-machine and SLURM
entrypoints:

``` r

# Full main-grid run. Writes ./results/sim_iv_raw.rds and sim_iv_table.csv.
source(system.file("paper-replication/iv/run.R", package = "RdistNN"))
```

``` bash
# On a SLURM cluster, after installing RdistNN:
sbatch /path/to/paper-replication/iv/hpc/submit.sh

# After the array tasks complete:
Rscript /path/to/paper-replication/iv/hpc/merge.R
```

Set `SIM_OUTDIR` before running these scripts to write results outside
the current working directory. The full grid uses 36 array cells and
10,000 replications per cell; package tests exercise the same scripts
through a small smoke grid instead of running the production simulation.
