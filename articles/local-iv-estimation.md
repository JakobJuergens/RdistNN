# Local IV-GMM Estimation

## Overview

> **Experimental.** The local IV-GMM interface may change. For the
> supported regression, CATE and conditional-LATE workflows, start with
> [Getting
> started](https://JakobJuergens.github.io/RdistNN/articles/getting-started.md)
> and [Conditional
> LATE](https://JakobJuergens.github.io/RdistNN/articles/conditional-late.md).

This vignette shows the local IV-GMM workflow built on
[`gmm_dnn()`](https://JakobJuergens.github.io/RdistNN/reference/gmm_dnn.md).
The example uses the doubly robust IV moment model created by
[`gmm_model_dr_iv()`](https://JakobJuergens.github.io/RdistNN/reference/gmm_model_dr_iv.md)
and the IV simulation DGPs exposed through
[`sim_iv_data()`](https://JakobJuergens.github.io/RdistNN/reference/sim_iv_data.md).

These synthetic IV examples are experimental benchmarks. The paper
replication is described in [Paper
replication](https://JakobJuergens.github.io/RdistNN/articles/paper-affine-replication.md).

## One Local IV Dataset

[`sim_iv_data()`](https://JakobJuergens.github.io/RdistNN/reference/sim_iv_data.md)
returns a data frame with observed variables, oracle nuisance columns,
the target point `x0`, and the true local IV target `theta_x0`.

``` r

iv <- sim_iv_data(
  design = "dgp2_iv_homog_overid",
  n = 160L,
  kx = 2L,
  q = 2L,
  seed = 1L
)

head(iv$data[, c("X1", "X2", "Z1", "Z2", "D", "Y")])
#>           X1         X2 Z1 Z2 D           Y
#> 1 -0.6264538  0.4251004  1  1 1 -0.25030342

iv$theta_x0

```

## Fitting the DR-IV GMM Model

The DR-IV model factory records which columns contain the outcome,
treatment, instruments, and nuisance estimates. In this example the
nuisance columns are oracle values generated by the DGP.

``` r

model_iv <- gmm_model_dr_iv(
  y_col = "Y",
  d_col = "D",
  z_cols = c("Z1", "Z2"),
  pi_cols = c("piZ1_oracle", "piZ2_oracle"),
  muY_col = "muY_oracle",
  muD_col = "muD_oracle"
)

fit_iv <- gmm_dnn(
  data = iv$data,
  x_cols = c("X1", "X2"),
  x0 = iv$x0,
  model = model_iv,
  k = 1L,
  s = 12L,
  se = TRUE,
  return = "ess"
)

fit_iv$theta
#>       target_1
#> theta  0.51562
fit_iv$se
#>        target_1
#> theta 0.7900163
fit_iv$J
#>   target_1 
#> 0.09635039
fit_iv$pval_J
#>  target_1 
#> 0.7562541
fit_iv$neff
#> target_1 
#> 24.67559
```

[`summary()`](https://rdrr.io/r/base/summary.html) and
[`confint()`](https://rdrr.io/r/stats/confint.html) expose the same
fitted object in reporting form:

``` r

summary(fit_iv)
#> <summary.gmm_result>
#>   model  : dr_iv

#>     target  term estimate std.error statistic p.value conf.low conf.high
#> 1 target_1 theta   0.5156      0.79    0.6527   0.514   -1.033     2.064
#> 
#> Overidentification diagnostics:
#>     target       J df p.value  neff
#> 1 target_1 0.09635  1  0.7563 24.68
confint(fit_iv)
#>     target  term  conf.low conf.high
#> 1 target_1 theta -1.032784  2.064023
```

## Small IV Simulation

[`sim_iv_run()`](https://JakobJuergens.github.io/RdistNN/reference/sim_iv_run.md)
expands a grid over designs, sample sizes, covariate dimensions,
instrument counts, and Monte Carlo replications. The just-identified
design `dgp1_iv_justid_linear` is always run only once with realized
`q = 1`. An explicit `master_seed` restores the caller’s saved RNG
state; `NULL` uses the current stream. Each replicate keeps data and
learner draws together.

``` r

raw_iv <- sim_iv_run(
  designs = c("dgp1_iv_justid_linear", "dgp2_iv_homog_overid"),
  n_vals = 120L,
  kx_vals = 2L,
  q_vals = 2L,
  n_reps = 2L,
  master_seed = 42L,
  k = 1L,
  s_fn = function(n, kx) 10L,
  methods = "iv_oracle",
  verbose = FALSE
)

raw_iv[, c("method", "design", "theta_hat", "se")]
#>      method                design  theta_hat        se
#> 1 iv_oracle dgp1_iv_justid_linear  0.2303256 0.5357276
#> 2 iv_oracle dgp1_iv_justid_linear -0.3883279 1.4282239
#> 3 iv_oracle  dgp2_iv_homog_overid  2.3101378 0.6245025
#> 4 iv_oracle  dgp2_iv_homog_overid  1.1725896 0.6264744
```

These two-replicate cells demonstrate the output format; they are not
coverage evidence.
[`summarise_iv_results()`](https://JakobJuergens.github.io/RdistNN/reference/summarise_iv_results.md)
aggregates to one row per `(method, design, n, kx, q)` cell and includes
local overidentification diagnostics when `q > 1`.

``` r

tab_iv <- summarise_iv_results(raw_iv)
print(tab_iv, digits = 3)
#>      method                design   n kx q n_reps n_failed   bias  rmse se_mean
#> 1 iv_oracle dgp1_iv_justid_linear 120  2 1      2        0 -0.079 0.319   0.982
#> 2 iv_oracle  dgp2_iv_homog_overid 120  2 2      2        0  0.530 0.777   0.625
#>   cover ci_len neff J_median pval_J_median reject_J
#> 1     1   3.85 21.9       NA            NA       NA
#> 2     1   2.45 21.9     3.12         0.333      0.5
```
