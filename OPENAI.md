# OpenAI session entry point

For a session that does not automatically load repository files, attach
[AGENTS.md](AGENTS.md), then the current control notes it requires for the task
and the exact source files to be discussed or edited. For package work,
include the relevant numbered design notes under `markdown_notes/design/`.
A file path in a prompt does not give a chat session access to its contents.

[AGENTS.md](AGENTS.md) is the canonical instruction file; [README.md](README.md)
provides orientation. Follow their live read order, verification rules, and
literature workflow. Keep project status and machine-specific guidance in those
maintained sources rather than duplicating them here.
