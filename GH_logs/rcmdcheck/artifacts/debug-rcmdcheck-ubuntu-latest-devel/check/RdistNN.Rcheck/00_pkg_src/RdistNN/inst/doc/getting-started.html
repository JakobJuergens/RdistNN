Getting started with RdistNN

library(RdistNN)

Overview

RdistNN provides:

  • Distance specifications and registries (new_distance(), register_distance())
  • Rank-weight specifications and registries (new_rank_weight(), register_rank())
  • Score specifications and differentiation helpers (new_score(), score_eval_batch(), score_diff_path())
  • DNN weight constructors (weights_dnn(), weights_dnn_exact(), weights_dnn_asymp())
  • User-level localized estimators:
    • np_dnn() for nonparametric local means
    • cate_dnn() for conditional average treatment effects
    • plqr_dnn() for localized orthogonal PLQR moments

Most user workflows are one of:

  1. Build weights directly and combine with your own signal.
  2. Use one of the user-level wrappers above.
  3. Customize distance and rank-weight rules through registries.
  4. Build your own score kernels and localized estimators on top of the same modular API.

1) Compute DNN Weights

set.seed(1)
n <- 120
p <- 2
X <- matrix(rnorm(n * p), n, p)
X0 <- matrix(rnorm(6), 3, p)

# Exact finite-sample DNN weights
wt_exact <- weights_dnn(
  X = X, X0 = X0,
  distance = "l2",
  method = "exact",
  k = 2L, s = 3L,
  return = c("W", "ranks", "ord")
)

# Asymptotic DNN weights
wt_asymp <- weights_dnn(
  X = X, X0 = X0,
  distance = "l2",
  method = "asymp",
  k = 2L, s = 3L,
  normalize = TRUE,
  return = "W"
)

dim(wt_exact$W)

For exact DNN weights, the package uses the full rank permutation at each target. This is not an s-nearest-neighbor truncation. In rank order, the exact finite-population support is j <= n - s + k, and in particular j <= n - s + 1 when k = 1.

2) Local Nonparametric Regression with np_dnn()

demo_np <- np_demo_data(n = 250, p = 2, design = "sinusoidal", seed = 1)

fit_np <- np_dnn(
  data = demo_np$data,
  x_cols = c("X1", "X2"),
  y_col = "Y",
  x0 = c(0, 0),
  method = "exact",
  k = 2L, s = 3L,
  se = TRUE,
  jackknife = "fast",
  return = c("W", "ess", "neighbors")
)

fit_np$mu
fit_np$se

jackknife can be:

  • "fast": delete-1 updates from full-sample ranks (default)
  • "loo": direct leave-one-out recomputation
  • "none": skip standard errors

3) CATE with cate_dnn() and Post-estimation Methods

demo_cate <- cate_demo_data(n = 300, p = 2, design = "hetero", seed = 1)
df <- demo_cate$data
df$m1_oracle <- df$m0_oracle + df$tau_oracle

fit_cate <- cate_dnn(
  data = df,
  x_cols = c("X1", "X2"),
  y_col = "Y",
  t_col = "D",
  m0_col = "m0_oracle",
  m1_col = "m1_oracle",
  e_col = "e_oracle",
  x0 = c(0, 0),
  method = "exact",
  k = 2L, s = 3L,
  se = TRUE,
  return = c("psi", "nuisance")
)

summary(fit_cate)
confint(fit_cate)
predict(fit_cate, x0 = c(0.2, -0.1), interval = "confidence")

cate_dnn() supports:

  • Matrix interface: pass X, X0/x0, and pseudo_outcome
  • Data-frame interface:
    • Full AIPW: y_col, t_col, e_col, m0_col, m1_col
    • Robinson-style: y_col, t_col, e_col, m_col

5) Customize Distance and Rank Rules

register_distance("linf_demo", function(X, x0, ctx = NULL) {
  apply(abs(X - matrix(x0, nrow(X), ncol(X), byrow = TRUE)), 1L, max)
})

register_rank("inv_rank_demo", function(ranks) {
  w <- 1 / as.numeric(ranks)
  w / sum(w)
})

X <- as.matrix(np_demo_data(n = 80, p = 2, seed = 1)$data[, c("X1", "X2")])

out <- weights_matrix(
  X = X,
  x0 = c(0, 0),
  ranking = "linf_demo",
  weight = get_rank("inv_rank_demo"),
  return = c("W", "ranks")
)
dim(out$W)

6) Minimal Custom Score

sc_affine <- new_score(
  name = "affine_order1",
  order = 1L,
  eval_param = function(idxs, data, theta, ctx, rng = NULL) {
    theta[1] * data$Y[idxs] + theta[2]
  },
  grad = function(idxs, data, theta, ctx, rng = NULL) {
    c(data$Y[idxs], 1)
  }
)

df <- data.frame(Y = c(1, 2, 4))
path <- score_diff_path(sc_affine, data = df, method = "auto")

path$value(2L, theta = c(0.5, 1))
path$grad(2L, theta = c(0.5, 1))

When you move beyond the built-in wrappers:

  • implement a custom distance if the notion of closeness changes;
  • implement a custom rank weight if the ranking stays the same but the localization profile changes;
  • implement a custom score if the target moment or estimating equation changes.

The full extension workflow, including setup(), eval_batch(), parameter-aware scores, and debugging with return = c("dx", "ord", "ranks"), is in vignette("extending", package = "RdistNN").
